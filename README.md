# 🌾 AgriPrice – Smart Farmer App

**A voice-enabled agricultural platform that helps farmers compare market prices, estimate profits, calculate transportation costs, and explore weekly price trends.**

🌐 **Live Website:** [Open AgriPrice](https://hema189.github.io/AgriPrice-App/)

## 📌 About the Project

AgriPrice is a farmer-friendly web application designed to make agricultural market information easier to access. It provides a simple interface and voice interaction to support farmers, including users who prefer regional languages.

The application supports Telugu, Hindi, and English language selection and provides tools to help farmers make more informed selling decisions.

## ✨ Features

- 🌐 **Multilingual Interface:** Telugu, Hindi, and English language selection.
- 🎤 **Voice Assistance:** Voice input and spoken responses using browser speech capabilities.
- 🌱 **Crop Selection:** Paddy, Tomato, Cotton, Maize, Mango, Moong, and Sunflower Seed.
- 📍 **Market Price Comparison:** Compare sample prices across different markets.
- 💰 **Profit Calculator:** Estimate revenue, costs, and profit based on quantity and entered expenses.
- 🚚 **Transport Cost Calculator:** Estimate transportation costs using distance and cost per kilometre.
- 🌦️ **Weather Information:** Display weather information in the prototype.
- 📊 **Weekly Price Graph:** Visualize sample market price trends across seven days.
- 🖼️ **Visual Interface:** Crop images and a farmer-friendly dashboard.

## 🚀 Run the Project Locally

### Prerequisites

- Visual Studio Code
- Google Chrome or another modern browser
- Internet connection for the external libraries

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Hema189/AgriPrice-App.git
   ```

2. Open the project folder:

   ```bash
   cd AgriPrice-App
   ```

3. Open the folder in Visual Studio Code.

4. Install the **Live Server** extension if you do not already have it.

5. Right-click `index.html` and select **Open with Live Server**.

6. Test the application in your browser.

## 📊 Current Project Status

AgriPrice is currently a **frontend prototype**. Market prices, weekly graph values, and weather information are sample or static data. Live agricultural market APIs, real-time weather services, backend integration, and database support can be considered for future development.

Voice recognition depends on browser support, microphone permission, and the selected language.

## 🔮 Future Enhancements

- Integrate live agricultural market prices.
- Connect to a real-time weather API.
- Improve regional-language voice recognition.
- Add a backend and database for user preferences and market data.
- Provide notifications about price changes.
- Improve accessibility for farmers with limited reading ability.
