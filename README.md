# 🌾 AgriPrice – Smart Farmer App

A voice-enabled agricultural web application that helps farmers compare market prices, estimate profits, calculate transportation costs, and view weekly market price trends.

**Live Website:** https://hema189.github.io/AgriPrice-App/

**GitHub Repository:** https://github.com/Hema189/AgriPrice-App

## Features

- Multilingual language selection: Telugu, Hindi, and English.
- Voice input and spoken responses.
- Crop selection: Paddy, Tomato, Cotton, Maize, Mango, Moong, and Sunflower Seed.
- Market price comparison.
- Profit and loss estimation.
- Transportation cost calculation.
- Weather information display.
- Weekly market price graph.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Hema189/AgriPrice-App.git
   ```

2. Open the `AgriPrice-App` folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Current Status

This project is a frontend prototype. Market prices, weekly graph values, and weather information currently use sample or static data. Live market APIs, real-time weather integration, backend services, and database support are potential future enhancements.
